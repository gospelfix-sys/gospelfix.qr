# 가스펄픽스 입금 안내 — Style Reference
> QR 스캔 후 계좌 정보를 보여주고 금융앱 송금 화면으로 넘겨주는 중간 페이지. 절제된, 또렷한, 신뢰감 있는.

**Theme:** light
**Platform:** mobile 390×844 기준, 데스크톱에서도 `max-w-sm` 한 칸
**UI 기반 (필수):** shadcn/ui 컴포넌트(base-nova). 모든 UX/UI는 shadcn 컴포넌트를 기반으로 만든다. 새 UI는 shadcn에 있는지 먼저 확인하고 `npx shadcn@latest add <이름>`으로 추가한다. `asChild` 금지, 색은 변수 클래스(`bg-primary` 등)로만 참조

## Colors
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | #FFFFFF | 화면 배경 |
| 표면 | #F9FAFB | 입금 정보 표 |
| 글자 기본 | #111827 | 제목, 본문, 값 |
| 글자 보조 | #6B7280 | 라벨, 안내·고지 |
| 테두리 | #E5E7EB | 표 경계, 행 구분선 |
| 포인트 색 | #000000 | 주 버튼(계좌번호 복사)에만 |
| 포인트 옅은 것 | #F3F4F6 | 보조 버튼 hover/active |

바탕이 표면보다 밝다. 카드 경계는 테두리 1px가 함께 잡는다.

## Typography
- Font: 시스템 폰트 (웹폰트·외부 폰트 금지)
- 화면 제목 18px / 600, 버튼 글자 16px / 600, 본문·값 13px / 400(값 600), 섹션 제목 13px / 600, 부가·고지 11px / 400
- 굵기는 400과 600만. 계좌번호만 `font-mono`
- 행간: 본문·고지 relaxed, 제목 기본

## Spacing
- 4·8·12·16·24·32만 쓴다. 그 사이 값은 쓰지 않는다
- 화면 좌우 16 / 위아래 32, 표 행 16×12, 섹션 사이 16, 섹션 안 8

## Radius
- 버튼 8px, 카드 12px, 원형은 999

## Elevation
- 테두리 1px만 쓴다. 그림자·그라데이션·블러 없음

## Components (shadcn)
- 주 버튼: shadcn `Button` default — 검정 배경 + 흰 글자, 높이 48px, 화면당 하나("계좌번호 복사")
- 보조 버튼: shadcn `Button` outline — 흰 배경 + 테두리 1px, 높이 48px — 금융앱 링크(`<a className={buttonVariants(...)}>`, 텍스트만, 로고 없음)
- 카드: shadcn `Card` — `bg-card`, 12px, 테두리 1px, 그림자 없음
- 입력창·칩·배지·탭: 없음

## Guidelines

### DO
- UX/UI는 shadcn 컴포넌트 기반. 있는 UI는 직접 만들지 않고, 모양 변경은 `components/ui/*` 정의 파일에서
- 포인트 색은 주 버튼에만 쓴다
- 입력(fragment)은 `parseTransfer`를 거친 값만 쓴다
- "제휴 아님 + 보내기 전 확인" 고지와 "계좌번호 복사"를 항상 보여준다
- 용어는 "송금/입금"

### DON'T
- 표 밖의 색·굵기·간격·모서리 값 금지
- 그림자·그라데이션·글로우 금지
- 외부 요청(웹폰트·CDN·분석) 금지, 계좌정보를 query·저장소·로그로 옮기기 금지
- 금융앱 로고 금지, "결제" 표현 금지, 면책 단정 문구 금지
