# 가스펄픽스 입금 안내 — Style Reference
> QR을 스캔한 구매자에게 판매자 계좌 정보를 보여주고 금융앱 송금 화면으로 넘겨주는 한 장짜리 중간 페이지. 절제된, 또렷한, 신뢰감 있는.

**Theme:** light (다크 테마 없음)
**Platform:** mobile 390×844 기준 (QR을 폰으로 스캔해서 진입). 데스크톱에서 열려도 `max-w-sm`(384px) 한 칸으로 가운데 정렬

**UI 기반:** shadcn/ui 컴포넌트(`base-nova`, 사용자 앱과 동일). 모든 UX/UI는 shadcn 컴포넌트를 기반으로 만든다 → `07-components.md`

## 이 프로젝트에서 분위기 단어를 이렇게 골랐다

- **절제된**: 돈과 계좌번호가 나오는 화면이라 장식이 없어야 한다. 의심을 살 요소(그라데이션, 큰 일러스트, 광고성 문구)를 넣지 않는다.
- **또렷한**: 은행·계좌·예금주·금액을 한눈에 읽고 확인해야 한다. 정보와 행동 버튼의 위계를 분명히 한다.
- **신뢰감 있는**: 피싱 링크와 나란히 놓여도 믿을 수 있어 보여야 한다. 규칙적인 여백, 단단한 대비, 제휴 아님·확인 안내 상시 노출.

세 단어가 가리키는 방향: 무채색 중심 / 굵기 차 작게 / 모서리 작게 / 그림자 없이 / 테두리로 구분.

## 화면 구성 (총 2가지 상태, 라우트는 `/` 하나)

| 상태 | 언제 | 내용 |
|---|---|---|
| 정상 | fragment가 유효 | 얇은 헤더 → 보낼 금액(가장 큼) → 입금 안내 표 → 금융앱 타일 4열 → 안내 3단계·고지 문구, 하단 고정 바에 "계좌번호 복사" |
| 유효하지 않음 | fragment 누락·변조·범위 초과 | 헤더 + 안내 한 줄(`role="alert"`) |

로딩 중에는 아무것도 그리지 않는다(fragment는 마운트 후에만 읽을 수 있고, 깜빡임이 짧다).
