# 04. Spacing — 간격

## Spacing
- 간격은 4·8·12·16·24·32만 쓴다. 그 사이 값은 쓰지 않는다 (Tailwind `1·2·3·4·6·8`)
- 화면 좌우 여백 16px — `px-4`
- 화면 위아래 여백 32px — `py-8`
- 입금 정보 표 행 안쪽 여백 좌우 16px / 위아래 12px — `px-4 py-3`
- 섹션과 섹션 사이 16px — `space-y-4`
- 버튼과 버튼 사이, 섹션 제목과 버튼 사이 8px — `space-y-2`
- 라벨-값처럼 한 쌍으로 읽히는 요소 사이 8px — `gap-2`

## 이 프로젝트의 결정

- **기준 단위는 4px.** 임의값(`mt-[10px]`, `gap-[14px]`)을 쓰지 않는다. 글자 크기 임의값(`text-[13px]`, `text-[11px]`)은 03번 표에 있는 것만 예외.
- **한 칸 레이아웃이다.** `max-w-sm`(384px) 컨테이너를 `mx-auto`로 가운데 두고, 390px 폭 폰에서는 좌우 16px만 남는다. 더 넓은 화면에서도 컨테이너 폭을 키우지 않는다.
- **묶임 규칙**: 표 → 복사 버튼 → 금융앱 섹션 → 고지 순서로 모두 16px, 같은 섹션 안(제목-버튼, 버튼-버튼)은 8px. 안쪽 간격이 바깥 간격보다 넓어지지 않게 한다.
- **스케일은 6단계**(4·8·12·16·24·32)이며, 현재 화면은 8·12·16·32만 쓴다. 24는 카드가 늘어날 때를 위해 남겨둔다.

## 체크리스트
- [ ] 4의 배수(Tailwind 기본 스케일)만 썼는가
- [ ] `[Npx]` 임의 간격이 없는가
- [ ] 섹션 사이(16) > 섹션 안쪽(8) 순서가 지켜졌는가
- [ ] 컨테이너 폭을 `max-w-sm`에서 넓히지 않았는가
