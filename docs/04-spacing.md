# 04. Spacing — 간격

## Spacing
- 간격은 4·8·12·16·24·32만 쓴다. 그 사이 값은 쓰지 않는다 (Tailwind `1·2·3·4·6·8`)
- 화면 좌우 여백 16px — `px-4`
- 본문 영역 위아래 여백 24px — `pt-6 pb-6`(헤더 아래, 하단 고정 바 위)
- 유효하지 않음 안내 화면 위아래 여백 32px — `py-8`(`InvalidLink`)
- 입금 정보 표 행 안쪽 여백 좌우 16px / 위아래 12px — `px-4 py-3`
- 섹션과 섹션 사이 24px — `space-y-6`(금액·입금 정보·앱 타일·안내)
- 안내 3단계와 고지 문구 사이 16px — `space-y-4`
- 앱 타일 사이(가로·세로), 섹션 제목과 타일 사이 8px — `gap-2` / `space-y-2`
- 하단 고정 바 안쪽 좌우 16px / 위아래 12px — `px-4 py-3`, 헤더 높이 48px — `h-12`
- 라벨-값처럼 한 쌍으로 읽히는 요소 사이 8px — `gap-2`

## 이 프로젝트의 결정

- **기준 단위는 4px.** 임의값(`mt-[10px]`, `gap-[14px]`)을 쓰지 않는다. 글자 크기 임의값(`text-[13px]`, `text-[11px]`)은 03번 표에 있는 것만 예외.
- **한 칸 레이아웃이다.** `max-w-sm`(384px) 컨테이너를 `mx-auto`로 가운데 두고, 390px 폭 폰에서는 좌우 16px만 남는다. 더 넓은 화면에서도 컨테이너 폭을 키우지 않는다.
- **묶임 규칙**: 금액 → 입금 정보 표 → 앱 타일 → 안내·고지 순서로 섹션 사이는 24px, 같은 섹션 안(제목-타일, 타일-타일)은 8px. 안쪽 간격이 바깥 간격보다 넓어지지 않게 한다. 주 버튼은 본문 흐름이 아니라 하단 고정 바에 있다.
- **스케일은 6단계**(4·8·12·16·24·32)이며, 현재 화면은 8·12·16·24·32를 쓴다(24는 섹션 사이와 본문 위아래).

## 체크리스트
- [ ] 4의 배수(Tailwind 기본 스케일)만 썼는가
- [ ] `[Npx]` 임의 간격이 없는가
- [ ] 섹션 사이(24) > 섹션 안쪽(8) 순서가 지켜졌는가
- [ ] 컨테이너 폭을 `max-w-sm`에서 넓히지 않았는가
