# 06. Elevation — 깊이

## Elevation
- 깊이는 **테두리** 하나만 쓴다
- 그림자와 배경색 차이를 깊이 표현으로 쓰지 않는다. 입금 정보 표는 테두리 1px(`border border-border`)와 행 구분선(`divide-y divide-border`)으로 구분한다
- `shadow-*`, `drop-shadow-*`, `ring-*`(장식용. 키보드 포커스 링 `--ring`은 허용), `backdrop-blur`를 쓰지 않는다

## 이 프로젝트의 결정

- **표면 색(`bg-card`)은 "깊이"가 아니라 "구분 표시"다.** 같은 요소에서 테두리가 경계를 잡고, 배경색은 입금 정보 영역임을 알려주는 용도일 뿐이다. 그림자와 함께 쓰지 않는다.
- **떠 있는 요소(모달, 드롭다운, 토스트)가 없다.** 이런 요소가 필요해지면 먼저 이 파일에 레이어 기준(예: "화면을 덮는 요소만 `shadow-lg`")을 한 문장으로 적고 추가한다. 지금은 단계 0개.
- 다크 테마가 없어 그림자 가독성 문제는 해당하지 않는다.

## 체크리스트
- [ ] `shadow`/`blur` 계열 클래스가 코드에 없는가
- [ ] 카드 경계가 테두리 1px로만 표현되는가
- [ ] 새 떠 있는 요소를 추가했다면 레이어 기준을 이 파일에 먼저 적었는가
