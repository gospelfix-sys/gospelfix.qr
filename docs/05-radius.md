# 05. Radius — 모서리

방식 1(자리마다 지정)을 쓴다. 자리가 버튼·카드 두 곳뿐이다. shadcn이 `--radius`를 읽으므로 기준값은 `09-shadcn-tokens.md`의 `--radius: 0.5rem`(8px) 하나이고, 파생값(`--radius-sm/md/lg`)을 개별로 덮어쓰지 않는다.

## Radius
- 버튼 8px — `rounded-lg` (shadcn Button 기본, `--radius` 기준)
- 입금 정보 표(카드) 12px — `rounded-xl` (shadcn Card 기본값이 다르면 `card.tsx`에서 맞춘다)
- 원형은 999 — `rounded-full`

## 이 프로젝트의 결정

- **값은 3종 이내**(8 / 12 / 999). 현재 `999`는 쓰는 곳이 없지만 원형 요소가 생기면 `rounded-full`만 쓴다. 크기의 절반을 계산한 값(`rounded-[22px]`)은 쓰지 않는다.
- **카드(12) ≥ 버튼(8).** 면적이 큰 표가 더 둥글다.
- **표 안쪽 행은 모서리를 따로 주지 않는다.** 표 컨테이너에 `overflow-hidden`을 걸어 바깥 모서리만 둥글게 보이게 한다.
- 모서리를 0으로 만들거나 알약형(버튼 999)으로 바꾸는 것은 01번 분위기("절제된·단단한")와 어긋나므로 하지 않는다.

- [ ] 카드가 버튼보다 같거나 큰가
