# 05. Radius — 모서리

방식 1(자리마다 지정)을 쓴다. shadcn이 `--radius`를 읽으므로 기준값은 `09-shadcn-tokens.md`의 `--radius: 1rem`(16px) 하나이고, 파생값(`--radius-sm/md/lg`)을 개별로 덮어쓰지 않는다. (2026-11-23: 0.5rem → 1rem. 가스펄픽스 브랜드 사이트와 같은 값으로 통일하기 위해 사용자가 결정)

## Radius
- 버튼·앱 타일·입력창·선택(트리거·팝업)·카드(입금 정보 표)·QR 틀 모두 16px — `rounded-2xl` (`--radius`와 같은 값)
- 원형은 999 — `rounded-full`

## 이 프로젝트의 결정

- **값은 2종**(16 / 999). 이전의 8 / 12 구분(버튼 8, 카드 12)은 폐지하고 `--radius` 하나로 합쳤다. 현재 `999`는 쓰는 곳이 없지만 원형 요소가 생기면 `rounded-full`만 쓴다. 크기의 절반을 계산한 값(`rounded-[22px]`)은 쓰지 않는다.
- **클래스는 `rounded-2xl`로 적는다.** Tailwind 기본 스케일에서 16px이 `rounded-2xl`이다. 이전에 쓰던 `rounded-lg`(8px)·`rounded-xl`(12px)은 쓰지 않는다. `tailwind.config.ts`가 아직 `borderRadius`를 `--radius`에 연결하지 않으므로, 클래스의 16px과 `--radius`의 16px을 따로 맞춰 둔다(값이 어긋나면 `docs/README.md`에 기록).
- **카드 ≥ 버튼.** 둘 다 16px이라 같다(면적이 큰 표가 더 작지 않다).
- **표 안쪽 행은 모서리를 따로 주지 않는다.** 표 컨테이너에 `overflow-hidden`을 걸어 바깥 모서리만 둥글게 보이게 한다. 높이 48px 요소에 16px을 쓰면 알약형이 되지 않는다(반지름이 높이의 3분의 1).
- 모서리를 0으로 만들거나 알약형(버튼 999)으로 바꾸는 것은 01번 분위기("절제된·단단한")와 어긋나므로 하지 않는다.

## 체크리스트
- [ ] "원형은 999" 한 줄이 있는가
- [ ] 값이 16 / 999 두 가지뿐인가 (`rounded-lg`·`rounded-xl` 없음)
- [ ] 버튼·타일·입력창·선택·카드·QR 틀이 모두 `rounded-2xl`인가
