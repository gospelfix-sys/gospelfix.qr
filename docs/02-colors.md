# 02. Colors — 색 7개

값은 가스펄픽스 브랜드 사이트(https://xn--o39aj34ba393o94b.com/)의 CSS 변수에서 가져와 이 화면에 맞게 조정한 것이다(조정한 이유는 아래 "대비"). 코드에서는 **shadcn CSS 변수로 참조**한다(`bg-card`, `text-muted-foreground` 등 → `09-shadcn-tokens.md`). 표 밖의 색을 추가하지 않는다. 표기는 HEX로 통일한다(OKLCH 사용 안 함).

## Colors
| 이름 | 값 | shadcn 변수 클래스 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | #F7F5F0 | `bg-background` | 화면 배경(따뜻한 베이지), 헤더·하단 고정 바 |
| 표면 | #FFFFFF | `bg-card` / `bg-popover` | 입금 정보 표(카드), 앱 타일·입력창·선택 트리거의 바탕, Select 팝업 |
| 글자 기본 | #111111 | `text-foreground` | 제목, 본문, 값(은행·계좌·금액). 오류·선택 2px 테두리(`border-foreground`) |
| 글자 보조 | #6B6B66 | `text-muted-foreground` | 항목 라벨, 안내·고지 문구, placeholder |
| 테두리 | #E8E5DF | `border-border` / `border-input` / `divide-border` | 표 경계, 행 구분선, 입력창·타일 테두리 |
| 포인트 색 | #FF5500 (주황) | `bg-primary` + `text-primary-foreground`(#111111) | **주 버튼(계좌번호 복사, QR 만들기)에만** |
| 보조 면 | #F0EEE8 | `bg-secondary` / `bg-muted` / `bg-accent` | 보조 버튼 hover/active 배경, 비활성 입력 배경(필요할 때만) |

이 외에 포커스 링 `--ring`은 #111111(글자 기본과 같은 값, 새 색이 아님), `--destructive`(#DC2626)는 정의만 두고 쓰지 않는다.

바탕이 베이지이고 카드는 흰색이다(방식 B). 즉 **카드가 바탕보다 밝다.** 카드 경계는 06번대로 테두리 1px(#E8E5DF)가 함께 잡는다.

## 이 프로젝트의 결정

- **(2026-11-23 변경) 포인트 색은 주황(#FF5500) 하나이고 베이지 중립색을 쓴다.** 이전 결정("포인트 색은 검정 하나, 주황은 쓰지 않는다. 팔레트는 Tailwind gray")을 사용자가 뒤집었다. 이유: 가스펄픽스 브랜드 사이트와 색을 통일하기 위해서다. 주황은 브랜드 사이트와 같은 색이라 알아보기 쉽고, 눌러야 할 곳(주 버튼 하나)에만 쓰므로 "눌러야 할 곳만 보인다"는 목적은 그대로 유지된다. 주황을 글자·테두리·링크·아이콘·배지에 쓰지 않는다.
- **오류·선택 표시는 주황이 아니라 검정이다(사용자 결정 유지).** 상태 색(성공/경고/오류)을 만들지 않는다. 복사 성공은 버튼 글자("복사됐어요")로 알린다. 오류 문구는 기본 글자색에 `font-semibold`(600) + `role="alert"`, 오류가 난 입력창·선택은 `aria-invalid` 시 검정 `border-foreground` 2px 테두리로, 선택된 앱 타일도 같은 방식으로 구분한다(07번). 이전에는 `border-primary`로 구현했지만 `--primary`가 주황이 되었으므로 반드시 `border-foreground`를 쓴다(오류가 주황이면 "빨강 금지·상태 색 없음" 규칙이 흐려진다). 빨강/초록을 추가해야 한다면 먼저 이 파일에 "이 외에는 만들지 않는다"와 함께 적는다.
- **`--primary-foreground`는 흰색이 아니라 #111111이다.** 브랜드 사이트는 주황 위에 흰 글자를 쓰지만 이 화면은 검정 글자를 쓴다. 흰 글자 vs #FF5500은 약 3.2:1로 4.5:1에 못 미치고, 검정 글자는 약 5.9:1이다.
- **`--muted-foreground`는 사이트의 #888이 아니라 #6B6B66이다.** #888은 베이지 바탕에서 약 3.2:1이라 11px 고지 문구의 4.5:1 기준에 못 미친다.
- **`--accent`에 사이트의 주황 틴트(rgba)를 쓰지 않는다.** 색을 늘리지 않기 위해 `--secondary`·`--muted`와 같은 #F0EEE8로 둔다.
- **`--ring`(포커스 링)은 주황이 아니라 #111111이다.** 주황은 베이지 바탕 대비가 약 2.9:1로 빠듯하다.
- shadcn 변수 중 `--destructive`(#DC2626)는 정의만 두고 화면에 쓰지 않는다. 색 7개 규칙의 예외가 아니라 미사용 자리표시다(`09-shadcn-tokens.md`).
- **대비**(WCAG 상대 휘도, 직접 계산):
  - 글자 기본 #111111 vs 바탕 약 17.3:1 / vs 카드 약 18.9:1 / vs 보조 면 약 16.3:1
  - 글자 보조 #6B6B66 vs 바탕 약 4.9:1 / vs 카드 약 5.4:1 / vs 보조 면 약 4.6:1(모두 4.5:1 이상). 고지 문구가 11px이라 보조 글자를 이보다 옅게 만들지 않는다. 테두리 색(#E8E5DF) 위에는 약 4.3:1이라 보조 글자를 테두리 색 면 위에 올리지 않는다.
  - 주 버튼 글자 #111111 vs 주황 #FF5500 약 5.9:1
  - 주황 면 vs 바탕은 약 2.9:1이다. 버튼 식별은 면 색이 아니라 5.9:1 글자와 위치(하단 고정 바)로 한다.
  - 테두리 #E8E5DF는 바탕과 약 1.15:1, 카드와 약 1.26:1로 장식적 구분선이다. 입력창처럼 경계가 핵심인 요소는 포커스 시 `--ring` 링과 2px 상태 테두리로 보완한다.

## 체크리스트
- [ ] 포인트 색이 1개인가 (주황 #FF5500, 주 버튼에만)
- [ ] 바탕(#F7F5F0)과 카드(#FFFFFF)의 밝기 관계(카드가 더 밝음, 테두리 1px가 경계)를 지켰는가
- [ ] 오류·선택 2px 테두리가 `border-foreground`(검정)이고 `border-primary`가 아닌가
- [ ] 주 버튼 글자가 `text-primary-foreground`(#111111)이고 주황이 글자·테두리·아이콘에 쓰이지 않았는가
- [ ] 글자 보조·고지 문구가 4.5:1 이상인 #6B6B66인가 (#888 아님)
- [ ] 새 색을 추가하기 전에 이 표에 먼저 넣었는가 (코드에 `gray-*` 팔레트·`blue-*` 등 표 밖 색이 없는가)
- [ ] HEX 한 가지 표기로 통일했는가
