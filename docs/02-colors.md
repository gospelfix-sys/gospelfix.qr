# 02. Colors — 색 7개

값은 Tailwind 3.4 gray 팔레트에서 고르고, 코드에서는 **shadcn CSS 변수로 참조**한다(`bg-card`, `text-muted-foreground` 등 → `09-shadcn-tokens.md`). 표 밖의 색을 추가하지 않는다. 표기는 HEX로 통일한다(OKLCH 사용 안 함).

## Colors
| 이름 | 값 | shadcn 변수 클래스 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | #FFFFFF | `bg-background` | 화면 배경 |
| 표면 | #F9FAFB | `bg-card` | 입금 정보 표(카드) |
| 글자 기본 | #111827 | `text-foreground` | 제목, 본문, 값(은행·계좌·금액) |
| 글자 보조 | #6B7280 | `text-muted-foreground` | 항목 라벨, 안내·고지 문구 |
| 테두리 | #E5E7EB | `border-border` / `divide-border` | 표 경계, 행 구분선 |
| 포인트 색 | #000000 | `bg-primary` + `text-primary-foreground` | 주 버튼(계좌번호 복사)에만 |
| 포인트 색 옅은 것 | #F3F4F6 | `bg-secondary` / `bg-muted` / `bg-accent` | 보조 버튼 hover/active 배경(필요할 때만) |

바탕이 표면보다 밝다. 표면은 바탕보다 한 단계 어두운 회색(방식 A)이고, 카드 경계는 06번대로 테두리 1px가 함께 잡는다.

## 이 프로젝트의 결정

- **포인트 색은 검정 하나.** 브랜드 색(주황)은 이 화면에 쓰지 않는다. 금융 정보 화면에서는 "눌러야 할 곳"만 보이게 하는 것이 목적이고, 색이 늘면 피싱 사이트와 구분이 어려워진다.
- **상태 색(성공/경고/오류)을 만들지 않는다.** 복사 성공은 버튼 글자("복사됨")로, 오류는 `text-muted-foreground` 안내 한 줄로 처리한다. 빨강/초록을 추가해야 한다면 먼저 이 파일에 "이 외에는 만들지 않는다"와 함께 적는다.
- shadcn 변수 중 `--destructive`(#dc2626)는 정의만 두고 화면에 쓰지 않는다. 색 7개 규칙의 예외가 아니라 미사용 자리표시다(`09-shadcn-tokens.md`).
- **대비**: 글자 기본 vs 바탕 약 17:1, 글자 보조 vs 바탕 약 4.8:1, 글자 보조 vs 표면 약 4.6:1(모두 4.5:1 이상). 고지 문구가 11px이라 보조 글자를 이보다 옅게 만들지 않는다.

## 체크리스트
- [ ] 포인트 색이 1개인가 (검정)
- [ ] 바탕/표면 밝기 관계를 적었는가
- [ ] 새 색을 추가하기 전에 이 표에 먼저 넣었는가 (코드에 `gray-*` 팔레트·`blue-*` 등 표 밖 색이 없는가)
- [ ] HEX 한 가지 표기로 통일했는가
